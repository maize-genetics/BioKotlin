# Terms

!!! note "Working notes"

    A glossary of terms used in BioKotlin's design discussions. See
    [Data structures](data-structures.md) for the model these describe.

**Funcalog** - an ortholog whose protein has the same biochemical
function and regulation: catalyzing the same reaction, binding the same
proteins in vitro, and able to be phosphorylated by the same kinases. There is
no subfunctionalization or neofunctionalization of the protein itself, though
the gene could be subfunctionalized or neofunctionalized.
